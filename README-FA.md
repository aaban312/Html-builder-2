# پی‌استودیو نسخهٔ ۲ — طراح بصری قالب‌های انکی

## امکانات جدید

- **۲۷ قالب آماده** شامل ۱۵ قالب قبلی + ۱۲ قالب حرفه‌ای: آزمایشگاه LaTeX، ماتریس تصمیم ۲×۲، نمودار ون، قیف تعاملی، نمودار میله‌ای، رادار، جدول حقیقت، شبکه مفاهیم، مقایسه با اسلایدر، هرم طبقات، نقشه حرارتی و نمودار تابع با اسلایدر.
- **۱۲ پالت رنگ:** ۹ تم تیره و **۳ تم روشن** (عاجی لوکس، آبی مه‌آلود، سبز مریم‌گلی).
- **فرمول‌های ریاضی / TeX با MathJax 3.2.1:** نمایش کسر، رادیکال، ماتریس، انتگرال، جمع، نمادهای ریاضی و دستورات پشتیبانی‌شده توسط MathJax. فایل نمایش آفلاین کتابخانه در `vendor/mathjax-tex-svg-full.js` بسته‌بندی شده است. این قابلیت MathJax TeX است، نه یک کامپایلر کامل LaTeX برای اسناد.
- **تصویر «نتیجهٔ کد» برای هر پروژه:** عکس JPG/PNG/WebP را از ویرایشگر انتخاب کن؛ به پیش‌نمایش کوچک تبدیل می‌شود و در فهرست شخصی و کتابخانه نمایش داده می‌شود. این تصویر وارد کد کارت انکی نمی‌شود.
- **سربرگ‌های قابل ایجاد:** «نمونه‌های آماده» و «قالب‌های من» جدا هستند. سربرگ‌های جدید با نام دلخواه (ریاضی، زبان، X، Y...) ایجاد، تغییر نام و حذف می‌شوند. انتخاب دسته برای هر پروژه از ویرایشگر انجام می‌شود؛ حذف سربرگ، پروژه‌ها را به «عمومی» منتقل می‌کند.
- **ذخیرهٔ کامل مجموعه HTML/CSS/JavaScript + تصاویر و دسته‌بندی‌ها** در مرورگر و پشتیبان‌گیری/بازیابی JSON.
- **پیش‌نمایش زندهٔ تعاملی و خروجی‌های جداگانه و نسبتاً فشردهٔ مخصوص انکی**. پروژه‌های قبلی در همان کلید ذخیره‌سازی نسخهٔ ۱ خوانده می‌شوند و به‌صورت خودکار به «عمومی» منتقل می‌شوند.

## اجرا و نصب

فایل‌های ZIP را استخراج کن، پوشه `anki-studio-pwa` را روی یک هاست استاتیک **HTTPS** (مانند GitHub Pages یا Netlify) یا localhost قرار بده، و `index.html` را باز کن. از قابلیت Install / افزودن به صفحه اصلی مرورگر برای نصب استفاده کن. Service Worker فایل‌ها و موتور MathJax را برای استفادهٔ آفلاین کش می‌کند. پیش از آفلاین‌شدن یک‌بار برنامه را با اتصال اینترنت باز کن تا کش کامل شود.

**نسخه تک‌فایلی:** فایل `pi-studio-v2-standalone.html` برای آزمایش سریع در مرورگر است و موتور MathJax را در خودش دارد؛ برای نصب PWA از نسخه ZIP استفاده کن. رفتار ذخیره‌سازی روی `file://` بسته به مرورگر ممکن است متفاوت باشد.

## نوشتن فرمول‌ها

برای فرمول مستقل می‌توان در ورودی مربوطه نوشت:

```tex
\frac{1}{3}
```

اگر متن و فرمول مخلوط هستند، حتماً جداکننده قرار بده:

```text
یک سوم برابر \(\frac{1}{3}\) است.
```

برای فرمول نمایشی و بزرگ:

```text
\[\int_0^1 x^2\,dx=\frac13\]
```

برای ماتریس:

```text
\[\begin{pmatrix}1&2\\3&4\end{pmatrix}\]
```

**نکته درباره انکی:** نسخه‌های جدید Anki، AnkiDroid و AnkiMobile پشتیبانی داخلی MathJax دارند؛ بنابراین **HTML خروجی شامل جداکننده‌های `\(` / `\[` می‌شود و نیازی به کپی‌کردن کتابخانهٔ بزرگ MathJax داخل هر کارت نیست**. این خروجی بر امکانات MathJax نصب‌شده در نسخه انکی شما تکیه دارد؛ برخی افزونه‌ها یا فرمان‌های خاص ممکن است بین نسخه‌ها متفاوت باشند. قابلیت مشاهده آفلاین فرمول‌ها در خود PWA از موتور بسته‌بندی‌شده استفاده می‌کند.

## متغیرهای عددی برای قالب اختصاصی

در HTML، CSS یا JavaScript، جایگزینی صرفاً برای الگوی دارای فاصله معمولی در دو طرف انجام می‌شود:

```html
<div> 01 </div><p> 02 </p><strong> 01 </strong>
```

هر شماره (01، 02، 12، 99...) یک ورودی ایجاد می‌کند. شماره‌های تکراری همان مقدار را می‌گیرند. شرط این است که قبل و بعد شماره یک فاصله ASCII باشد؛ `x01` یا `<p>01</p>` خودکار شناسایی نمی‌شوند.

## استفاده از خروجی در Anki

- HTML: داخل فیلد نوت یا بخش HTML قالب کارت
- CSS: داخل `Cards → Styling` یک‌بار برای هر نوت‌تایپ
- JavaScript: داخل `Front Template` یا `Back Template`، بعد از محل نمایش فیلد. همه قالب‌ها به JS نیاز ندارند.

کدهای خروجی تا حد ممکن مستقل و نام‌فضادارند و امکان تغییر پاسخ و گزینه‌ها فراهم است. دکمه «یکجا» برای آزمایش مرورگری است؛ نمایش MathJax در خروجی یکجای دانلودشده ممکن است به اتصال اینترنت نیاز داشته باشد. برای پیش‌نمایش کاملاً آفلاین از خود PWA استفاده کن.

## مدیریت عکس و ذخیره‌سازی

عکس‌ها هنگام انتخاب به تصاویر بندانگشتی فشرده تبدیل می‌شوند. چون پروژه‌ها، عکس‌ها و دسته‌بندی‌ها در localStorage ذخیره می‌شوند، محدودیت حجم مرورگر اعمال می‌شود؛ برای مجموعه‌های بزرگ، مرتب JSON پشتیبان بگیر. پشتیبان شامل نام‌ها، دسته‌بندی‌ها، تنظیمات، تصاویر و آخرین کدهای HTML/CSS/JS است. قالب‌های شخصی روی دستگاه‌های مختلف خودکار همگام نمی‌شوند.

## وابستگی‌ها و پروانه

برنامه بدون حساب کاربری و بدون سرور پشتیبان کار می‌کند. موتور MathJax 3.2.1 به شکل محلی در `vendor` قرار دارد و متن مجوز آن در `vendor/MATHJAX-LICENSE.txt` است.

## محدودیت فنی

- MathJax مجموعه بزرگی از دستورهای TeX ریاضی/شیمی را اجرا می‌کند؛ قابلیت‌های سندنویسی LaTeX مانند جدول‌آرایی گسترده، شکل‌های TikZ یا کامپایل فایل `.tex` در این ابزار پیاده نشده‌اند.
- JavaScript سفارشی در iframe جدا اجرا می‌شود ولی کد ناشناس را بدون بررسی اجرا نکن.
- این نسخه برای ذخیره‌سازی از localStorage استفاده می‌کند؛ اگر مرورگر داده‌ها را پاک کند ممکن است پروژه‌ها حذف شوند.
- پیش‌نمایش و عملکرد دقیق ابزارهای تعاملی باید روی نسخهٔ AnkiDroid یا Anki مورد استفاده امتحان شوند.
